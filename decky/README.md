# Whisker Decky Plugin

Decky Loader plugin for [Whisker](https://github.com/cgrd/whisker), a local speech-to-text tool.

## Features

* Start/stop Whisker service from Steam Deck's Quick Access menu
* Toggle auto-start on login
* Adjust noise gate threshold
* Pick transcription model

## Install

Install [Decky Loader](https://decky.xyz) on your Steam Deck, then install this plugin from the Decky store (or sideload manually).

Whisker must be installed separately. See the [Whisker repo](https://github.com/cgrd/whisker) for instructions.
